# FloatClock 全功能版（V9）EXE 程序使用介绍

轻量悬浮计时器：正计时 / 倒计时（红字白描边）/ 零点行为可选 / 全局热键 / 性能优化 / 位置记忆  
Windows 透明色悬浮显示（纯文字悬浮效果）

提示：本页内容用于 FCguide.html 的用户说明（EXE 版本）。无需安装 Python。

---

## 快速开始

- 系统要求
  - Windows 10/11（建议 64 位）
  - 无需安装 Python 或其他运行环境
- 下载与运行
  - 下载 FloatClockV9.exe 到任意文件夹
  - 双击运行
  - 首次启动会弹出“两步验证”对话框，输入有效的 6 位 TOTP 验证码后进入应用
- 权限提示
  - 如需启用全局热键但遇到拦截，可尝试右键以“管理员身份运行”
  - 若被安全软件或 Windows SmartScreen 拦截：选择“更多信息”→“仍要运行”，并将程序加入白名单

说明：两步验证对话框提供“查看验证密钥”按钮，便于在浏览器中查看并配置到你的身份验证器。密钥仅在本地使用。

---

## 两步验证（TOTP）

- 验证码每 30 秒更新，对话框显示当前验证码剩余时间
- 支持时间漂移容忍度：±1 个 30 秒步进
- 输入错误或过期会提示重试；可按“退出”离开程序
- 点击“查看验证密钥”将打开默认浏览器以查看/配置密钥

安全提示：密钥仅用于本地校验；应用不上传任何验证码或计时数据。浏览器仅用于打开说明/密钥页面。

## 界面与交互

- 无边框可拖动悬浮窗，支持位置记忆与置顶切换
- 显示颜色
  - 倒计时：红字 + 白色描边，增强可读性
  - 正计时：天蓝色
  - 暂停：灰色（倒计时暂停仍保持红色）
- 悬停交互
  - 在窗口上方悬停会显示控制按钮栏（暂停 / 重置 / 切换模式 / 设置倒计时 / 退出）
- 便捷操作
  - 双击计时区域：暂停/继续
  - 鼠标滚轮：调整字体大小
- 透明处理（Windows）
  - 使用指定背景色（默认 lightgray）作为透明色，实现纯文字悬浮
  - 如自定义背景色与透明色冲突，可能导致意外透明或闪烁，建议保持默认或避开 lightgray

## 计时模式与行为

- 正计时（Stopwatch）
  - 从 0 累计计时，以天蓝色显示
  - 每整分钟可选提示音（默认开启）
- 倒计时（Countdown）
  - 红字显示剩余时长，支持小时/分钟/秒设置
  - 触零行为（在“设置倒计时”中可选）
    - 继续负数倒计时（示例：-00:05）
    - 自动转为正计时（显示超时后的加班时长）
    - 自动暂停在 00:00（停止运行并停在零点）
  - 触零会提示音
- 显示格式
  - 当小时为 0 且未启用显示小时时，显示为 MM:SS；否则显示为 HH:MM:SS

## 快捷键与菜单

- 全局热键（默认启用；若被系统拦截可尝试管理员运行）
  - Ctrl + Alt + Space：暂停/继续
  - Ctrl + Alt + R：重新计时
  - Ctrl + Alt + C：切换模式
  - Ctrl + Alt + S：设置倒计时
  - Ctrl + Alt + Q：退出
  - Ctrl + Alt + ↑ / ↓：增/减字体大小
  - 如无法注册全局热键（权限或兼容性原因），应用会自动降级为窗口内快捷键
- 窗口内快捷键
  - Space：暂停/继续
  - R：重新计时
  - Q：退出
  - 双击计时区域：暂停/继续
  - 鼠标滚轮：调整字体大小
  - 右键：打开上下文菜单（置顶切换、模式/设置等）

## 常见问题（FAQ）

1. 全局热键不生效怎么办？
   - 尝试右键以“管理员身份运行”以允许键盘钩子
   - 关闭或放行可能拦截键盘钩子的安全软件
   - 不影响基本使用，应用会自动使用窗口内快捷键

2. 为什么倒计时到 0 有时会显示负数？
   - 属于“继续负数倒计时”行为的正常表现
   - 可在“设置倒计时”改为“自动转为正计时”或“自动暂停在 00:00”

3. 字体大小如何调整？
   - 鼠标滚轮直接调节；或使用全局热键 Ctrl + Alt + ↑ / ↓

4. 计时器为什么总在最前？
   - 默认置顶以提升可见性；可在右键菜单“置顶切换”中关闭

5. 提示音太频繁/太轻怎么办？
   - 正计时仅在“每整分钟”提示；倒计时仅在“到 0”时提示
   - 可根据需要在系统设置中调整提示音或在应用内关闭相关选项

6. 两步验证总是失败？
   - 确认验证器使用同一密钥
   - 验证码在 30 秒内有效，对话框会显示剩余时间
   - 应用容忍 ±1 个 30 秒步进的时间漂移；校准系统时间可提升成功率

7. Windows SmartScreen 提示阻止运行？
   - 点击“更多信息”→“仍要运行”
   - 将 FloatClockV9.exe 加入你的安全软件白名单

8. 如何开机自启？
   - Win + R 输入：shell:startup
   - 将 FloatClockV9.exe 复制到打开的“启动”文件夹

## 故障排查

- 窗口不可见或闪烁
  - 自定义背景色与透明色冲突会导致异常透明，建议使用默认或避开 lightgray
- 滚轮无效
  - 在某些设备或驱动环境下滚轮事件可能异常，可使用快捷键 Ctrl + Alt + ↑ / ↓
- 菜单不出现
  - 请在计时区域右键；或检查是否有全屏应用拦截鼠标事件
- 全局热键仍不可用
  - 尝试以管理员运行；或暂时关闭安全软件后测试
